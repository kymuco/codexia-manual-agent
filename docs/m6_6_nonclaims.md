# M6.6 Non-Claims

The first general daily-use pilot intentionally does **not** claim:

- a resident background daemon, cron service, wake-up timer, or notification system;
- a general autonomous-agent mode;
- arbitrary local process, filesystem, Git, merge, browser, network, or machine authority;
- a transport-independent worker bus beyond the existing ChatGPT peer-loop proof;
- that cognition-model output is an admission, permission, or execution authority by itself;
- that a worker may declare delegated work complete;
- that old worker evidence remains valid completion evidence after newer human/external activity;
- that an ambiguous provider effect is safe to retry;
- that the ephemeral cognition conversation is durable state or a source of truth;
- that unit/integration tests alone prove daily-use product value;
- that M6.6 is complete before both required real verticals are run and reviewed.

The pilot exists to test one narrower claim:

```text
already-governed delegated work can keep moving through routine worker cycles
without the human acting as the event loop,
while stopping when human judgment is genuinely required.
```
