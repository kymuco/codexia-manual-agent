# M6.3 Explicit Non-Claims

M6.3 proves one bounded live ChatGPT/Codexia peer-turn surface. It does not claim:

- background or unattended scheduling;
- durable work-queue persistence;
- cryptographic physical-human authentication;
- reliable authorship attribution for pre-attachment history;
- arbitrary multi-writer coordination on one ChatGPT conversation;
- automatic semantic extraction of the best next action from arbitrary worker prose;
- dynamic learned attention preferences;
- notification delivery;
- local process, filesystem, Git, or network authority;
- automatic execution after a semantic ADMIT;
- that a ChatGPT answer alone means delegated work is complete.

Those boundaries remain explicit so M6.3 cannot be mistaken for the later M6.4–M6.7 runtime.
